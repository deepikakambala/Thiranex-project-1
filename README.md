# Titanic Dataset - Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python. The main goal is to clean the dataset, understand its structure, visualize important patterns, and identify outliers.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## EDA Steps

### 1. Duplicate Values

Checked the dataset for duplicate records and handled them where necessary.

### 2. Missing Values

Identified missing values in the dataset and handled them appropriately.

### 3. Data Visualization

Created different visualizations to understand the data and identify important patterns and distributions.

### 4. Outlier Detection

Detected outliers in numerical columns such as:

* Age
* Fare
* SibSp
* Parch

The identified outliers were handled during the data preprocessing stage.

## Key Findings

* Most passengers belonged to 3rd class.
* Female passengers had a higher survival rate than male passengers.
* 1st-class passengers had a higher survival rate compared to 3rd-class passengers.
* Outliers were identified in Age, Fare, SibSp, and Parch.

## Project File

The complete analysis is available in the Jupyter Notebook:

**Titanic_EDA.ipynb**

## Conclusion

The Titanic dataset was successfully cleaned and explored using EDA techniques. Data cleaning, visualization, and outlier analysis helped in understanding the important patterns present in the dataset.
